Goal: compare the Graha/Lunar-FM semantic segmentation model against the
existing LFM toy semantic segmentation model using as similar an experiment as
possible.

Core principles:
- Maintain paired notebook and script artifacts for each workflow.
- The notebook is for interactive Jupyter development, debugging, plots, and
  inspection.
- The .py script contains the same training/evaluation logic in functions with
  a main() block so it can be launched with sbatch and run unattended.
- Keep shared logic in importable Python helpers where practical so the
  notebook and sbatch script do not drift.
- Move linearly: start one next step, finish and smoke-test it, then mark it
  completed before moving on.
