Instance Segmentation Controlled Smoke Tests
============================================

Purpose
-------

Smoke-test the active instance segmentation paths with controlled dataset and
training arguments before longer Toy vs Graha comparisons.

Assumed HPC Paths
-----------------

These commands assume:

- repo root:
  `/explore/nobackup/people/ajkerr1/Lunar_FM/full_model_lfm/lfm`
- instance dataset:
  `/explore/nobackup/projects/lfm/model_inputs/300_300_inputs/full_model_inst_seg_v2`
- Graha pretrain dir:
  `/explore/nobackup/people/ajkerr1/Lunar_FM/sandy_graha_pretrain_dir`

Shared Arguments
----------------

Use these controlled variables across Toy and Graha whenever possible:

```bash
COMMON_ARGS=(
  --data-root /explore/nobackup/projects/lfm/model_inputs/300_300_inputs/full_model_inst_seg_v2
  --graha-pretrain-dir /explore/nobackup/people/ajkerr1/Lunar_FM/sandy_graha_pretrain_dir
  --max-epochs 2
  --target-size 256
  --image-glob '*.tif'
  --label-glob '*_label.npz'
  --image-suffix '_input_wac_chip'
  --label-suffix '_label'
  --max-train-samples 5
  --max-val-samples 5
  --max-test-samples 5
  --batch-size 2
  --graha-batch-size 2
  --graha-stats-batch-size 4
  --band-filter 0 1 2 3 4 5 6
  --normalize-inputs
  --normalization-source pretrain
  --normalization-modality vis_uv
  --disable-toy-gradient-clipping
  --graha-input-modality-mode new-wac
  --prediction-split val
  --prediction-n-samples 5
  --prediction-score-threshold 0.5
  --run-epoch-test-suite
  --epoch-test-split test
  --epoch-test-n-samples 5
  --epoch-test-every-n-epochs 1
)
```

Target Contract Audit
---------------------

Run this first. It does not train or load model weights.

```bash
python -u scripts/python/instance_seg/instance_target_contract_audit.py \
  --data-root /explore/nobackup/projects/lfm/model_inputs/300_300_inputs/full_model_inst_seg_v2 \
  --target-size 256 \
  --image-glob '*.tif' \
  --label-glob '*_label.npz' \
  --image-suffix '_input_wac_chip' \
  --label-suffix '_label' \
  --band-filter 0 1 2 3 4 5 6 \
  --batch-size 2 \
  --num-workers 0 \
  --max-train-samples 5 \
  --max-val-samples 5 \
  --max-test-samples 5 \
  --output-json scripts/outputs/instance_target_contract_audit.json
```

Expected result:

- `toy_mask2former`, `toy_dino_mask_rcnn`, and `graha_mask_rcnn` all produce
  object targets with `xyxy` boxes, integer labels, and binary masks.
- Box counts, label counts, and mask counts are internally consistent.
- Boxes are inside the image and have positive area.

Checkpoint Sweep Smoke Tests
----------------------------

After smoke checkpoints exist, run one checkpoint per Toy architecture.

```bash
sbatch scripts/shell/instance_seg/sbatch_instance_checkpoint_sweep.sh \
  --data-root /explore/nobackup/projects/lfm/model_inputs/300_300_inputs/full_model_inst_seg_v2 \
  --output-root /explore/nobackup/people/ajkerr1/Lunar_FM/graha_vs_toy_experiments/smoke/iseg_mask2former_checkpoint_sweep \
  --models toy \
  --toy-architecture mask2former \
  --max-checkpoints 1 \
  --max-samples 5 \
  --target-size 256 \
  --image-glob '*.tif' \
  --label-glob '*_label.npz' \
  --image-suffix '_input_wac_chip' \
  --label-suffix '_label' \
  --batch-size 2 \
  --band-filter 0 1 2 3 4 5 6 \
  --normalize-inputs \
  --normalization-source pretrain \
  --normalization-modality vis_uv \
  --toy-checkpoint-dir /path/to/toy_mask2former_checkpoints
```
