# WAC STATIC BAND DESCRIPTIONS

This is a reference for anyone looking to understand what bands are present in the WAC + Static dataset.

Each band has two indices:

* **Absolute index** — the band index within the full combined dataset.
* **Relative index** — the band index within its individual modality. Use this index when selecting channels from a modality in the notebook data dictionary.

* **Absolute 1 | Relative 1** — `vis.mos-1`
